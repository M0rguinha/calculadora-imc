# 🏥 Calculadora de IMC

Uma calculadora simples e educativa para calcular o Índice de Massa Corporal (IMC) em Python.

## 📋 O que é IMC?

O Índice de Massa Corporal (IMC) é um indicador de gordura corporal que relaciona o peso e a altura de uma pessoa.

**Fórmula**: IMC = Peso (kg) / Altura² (m)

## 📊 Classificações

| IMC | Classificação |
|-----|----------------|
| < 18.5 | Abaixo do peso |
| 18.5 - 24.9 | Peso normal |
| 25 - 29.9 | Sobrepeso |
| 30 - 34.9 | Obesidade grau I |
| 35 - 39.9 | Obesidade grau II |
| ≥ 40 | Obesidade grau III |

## 🚀 Como usar

### Pré-requisitos
- Python 3.x instalado

### Executar
```bash
python calculadora_imc.py
```

### Exemplo de uso
```
Digite seu peso corporal (kg): 70
Informe sua altura (m): 1.75

========================================
Peso: 70.0 kg
Altura: 1.75 m
IMC: 22.86
Classificação: Peso normal
========================================
```
